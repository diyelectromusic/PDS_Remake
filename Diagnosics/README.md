# PDS Remake Diagnostics Breakout

This contains the hardware design files for a 16-way IDS diagnostic breakout board for use with a PDS.

# Important

Please refer to the main repository [readme](../README.md) for licensing, copyright, and limitations of use.

# Bill of Materials

* Diagnostic Module PCB
* 16x 3mm rectangular LEDs (colours to taste, but take note of the above discussion re impact of forward volage on the current calculation).
* 2x 8-way (9 pin) 2K or higher resistor networks (again see previous discussion).
* 2x Shrouded 16-way (2x8) header pins.
* 1x 2x8 header pins.
* Single row header pins.
* 16-way, straight through, IDC or similar ribbon cable (e.g. a Eurorack 16-way power cable).
